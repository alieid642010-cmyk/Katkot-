# دليل الرفع على GitHub — كتكوت برو

## الملفات (7 ملفات، كلها لازم تترفع فى **جذر الـ repo** مباشرة، مش جوه فولدر)

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق الكامل (الملف الرئيسي المبني بكل الإصلاحات والميزات) |
| `manifest.json` | بيانات التطبيق كـ PWA (الاسم، الألوان، الأيقونات) — لازم يكون ملف حقيقي منفصل عشان PWABuilder يقدر يقرأه |
| `sw.js` | Service Worker — بيخلي التطبيق يشتغل أوفلاين ويسمح بالإشعارات الخلفية |
| `icon-192x192-any.png` | أيقونة عادية 192×192 |
| `icon-512x512-any.png` | أيقونة عادية 512×512 |
| `icon-192x192-maskable.png` | أيقونة قابلة للقص (للأندرويد، بتتقص دائرية/مربعة حسب الجهاز) 192×192 |
| `icon-512x512-maskable.png` | نفس اللي فوق بحجم 512×512 |

**الأيقونات مصمَّمة خصيصًا** بنفس هوية التطبيق (خلفية خضراء غامقة `#1F2F26` + سنبلة قمح ذهبية `#D9A544`) — لو عندك أيقونة تانية مفضّلها، استبدل الملفات دي بس خلّي نفس الأسماء بالظبط.

## خطوات الرفع

1. افتح الـ repo بتاعك على GitHub (`eid6666-max` أو `alieid642010-cmyk` حسب اللي بتستخدمه).
2. ارفع الـ 7 ملفات دول فى **جذر الـ repo** (نفس المكان اللي فيه `index.html` القديم) — استبدل أي ملف بنفس الاسم موجود بالفعل.
3. تأكد إن GitHub Pages مفعّل: **Settings ← Pages ← Source: Deploy from branch ← اختار الـ branch والفولدر `/ (root)`**.
4. استنى دقيقة-دقيقتين، وافتح رابط الموقع (`https://username.github.io/repo-name/`) للتأكد إنه شغّال.

## بعد الرفع — تأكد من الآتي

- **افتح الرابط من جوجل كروم** (مش من جوه تطبيق تاني) وشوف هل ظهر زرار "📲 تثبيت التطبيق" فى الإعدادات.
- **افتح PWABuilder** (`pwabuilder.com`) وحط رابط موقعك — لازم يقرأ الـ `manifest.json` ويلاقي الأيقونات الأربعة من غير أخطاء قبل ما تعمل تحويل APK.
- **جرّب تفتح الموقع وتقفل النت** — لازم يفضل شغّال (ده معناه الـ `sw.js` اتسجّل صح).

## ملحوظة مهمة
لو غيّرت أي حاجة فى الكود بعد كده، لازم ترفع نسخة `index.html` جديدة كل مرة (هي الملف الوحيد اللي بيتغيّر عادةً — الباقي `manifest.json`/`sw.js`/الأيقونات بتفضل ثابتة إلا لو غيّرت اسم التطبيق أو شكل الأيقونة).
